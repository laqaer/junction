**If you use only Claude, never need to approve a step in the middle of a run, and are happy with Anthropic's cloud, your organisation's own environment, or Desktop scheduled tasks, use Routines, Channels and Remote Control.** They come with your plan and need no setup. Nothing here beats zero setup.

{site.name} is for the other cases: a harness that is not Claude, a run that has to stop and ask before `git push`, or a box of your own that you want the work to happen on, under a policy the agent cannot edit.

## What Anthropic's built-ins do well

- **Routines** run Claude Code on a schedule, from an API call or on a GitHub event, in Anthropic's cloud or on your organisation's self-hosted environment. Desktop scheduled tasks run on your own machine.
- **Channels** bring Telegram, Discord and iMessage into a Claude Code session.
- **Remote Control** lets you continue a local session from your phone or a browser.
- All three are Anthropic's own, and none needs a server of yours.

## Metering: paused, not cancelled

Anthropic planned to meter Agent SDK and third-party app use of Claude plans through a separate monthly credit, then paused the plan. For now, that use draws from your subscription's usage limits, and Anthropic says it will announce before any change. Claude Code reached through ACP is that kind of use. If the plan resumes, the "no cap from us" contrast above changes with it, and we will update this page.

The Claude Code session {site.name} starts runs under your own login, through the official CLI. For shared or production automation, use an API key, and read your vendor's terms for unattended use.
