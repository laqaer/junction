OpenClaw is a general personal agent: it runs its own agent loop and skills, and you reach it from a long list of chat apps. If you want one assistant for life admin as well as code, OpenClaw is the bigger and more general project, with a very large community around it. {site.name} does something narrower. It docks the coding CLI you already pay for, and puts a policy the agent cannot open in front of it.

## Where OpenClaw is ahead

- **Breadth.** It is a general assistant, not only a coding tool, with a skills ecosystem to match.
- **Channels.** It reaches more chat apps than our ten.
- **Community.** A very large one, with the documentation, guides and fixes that brings. We have none yet.

## When to pick which

Pick OpenClaw if you want one assistant for everything, reached from as many apps as possible. Pick {site.name} if what you want to text is a coding agent, and the thing you need is a written policy it cannot open, approvals before the risky step, and a log you can check the next morning.

We do not try to out-channel OpenClaw. We try to be the one your security team can read.
