# Owner inbox

Actions only the owner can take, written by the business roles and never
performed by them: spend, sign, post, create an account, record a night, set a
price, decide a kill or a pivot. Each item is dated and names the role that
raised it. The CEO review lists items open for more than seven days at the top of
the weekly status and moves completed items to Resolved. The standing checklist
of owner-only actions lives in [owner-actions.md](owner-actions.md); this file
holds what comes up between those.

## Item format

```text
### YYYY-MM-DD — <role> — <one-line title>   (prefix KILL Kn — for a tripped kill criterion)
- Needed: what the owner does, exactly.
- Why owner-only: spend / signature / identity / account / hardware / decision.
- Prepared: what the agent already drafted or checked, with file paths or links.
- Unblocks: the plan item, gate, or kill criterion this serves.
- Status: open | done YYYY-MM-DD
```
