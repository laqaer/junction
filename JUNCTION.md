checkout is Warding: it runs one docked coding agent on the operator's own
machine, on a schedule, reachable from chat, under a policy the agent cannot
read or rewrite. The file keeps its historical name so existing links resolve.

## Product (do not un-freeze)

- **Name:** Warding. One word, capital W, pronounced WAR-ding. Never
  "Warden", never "Ward". Company: Warding Labs.
- **CLI:** `warding`. `junction` is a silent alias: same entry point, no
  warning.
- **Tagline:** The lamp stays on. The rules stay shut. Short form: The lamp
  stays on.
- **One sentence:** Warding runs the coding agent you already pay for, all
  night, on your own box, and asks you in chat before anything risky — under
  a policy it cannot read or rewrite.
- **Lineage, line one of anything long:** Built on Amazon's open-source Kiro agent workspace, published under Apache-2.0 in 2026. Most of the code is theirs; the attribution notice is in NOTICE. Not affiliated with Amazon.
  Elsewhere call it the upstream project. The brand gate fails any added
  line that spells its retired product name (in any joining), its hosts, its
  bundle id or its GitHub organisation; the root `NOTICE` is the only
  exemption. Never Kiro in the product name, tagline, logo or domain.
- **Not the product:** Junction (the previous name), Codex Router, Hearth,
  Relay, Rudder, and the Warden cluster of other companies' products.
- **Visual:** paper and the Ward Seal by day; the night office by night. The
  seal is the only mark: no gradient, no glow, no lock body, never rotated,
  never next to the Amazon, AWS or Kiro marks. Sources: `assets/brand/`
  (generated by `assets/brand/build.py`), `assets/banner.svg`,
  `website/public/logo.svg`, `website/public/favicon.svg`.

## One harness, one desk, one catalog that is not a headline

1. **The docked harness** — the ACP runtime registry
   (`src/junction/acp/runtimes.py`). Default `agent.acp_backend` is `auto`.
   kiro-cli is optional and last. One harness at a time, set globally.
2. **The desk** — dashboard, CLI, ten chat apps, cron, task runner,
   subagents, memory, Agent Worlds. Inherited from the engine; this is where
   the product lives.
3. **The model catalog** — a loopback listener `warding up` starts
   (`src/junction/model_router/`). `GET /health` and `GET /catalog` only.
   Completion routes answer `501` `model_router_no_forward`. It lists names,
   forwards nothing, holds no keys, and is **never a headline**: no "route
   your models", no "model router", no "cheaper tokens" anywhere. If the
   listener is down, the gateway still runs; document that as degraded, never
   as a failure. `warding router` must not claim a sidecar injects keys.

## The NO-SAY list

command center, mission control (except the shipped scene's own name), agent
HQ, orchestrate, ADE, agentic IDE, autopilot, while you sleep, software
factory, autonomous software engineer, AI teammate, grows with you, learns how
you work, keep work moving, from anywhere, in your pocket, "any agent / no
lock-in / local-first" as a headline.

Untrue until the linked fix ships, never: side by side or parallel harnesses;
routes your models; works out of the box with Claude Code (say: via the ACP
project's `claude-agent-acp` adapter, fetched with `npx` on first run);
`pip install`; a published Docker image, desktop app or signed installer; a
hosted service, sign-up, teams or multi-user; overnight verified on any
harness; any star, user, customer, logo or testimonial; "nothing leaves your
machine"; audited, certified, unbreakable, sealed, physically, route around;
approvals from ten chat apps (it is five with buttons, one typed, four
chat-only).

Say only with the qualifier in the same sentence: "no run cap from us" (+
your model plan's limits still apply); "the agent you already pay for" (+
launched under your own login via the official CLI); "refused" (+ the
mechanism: built-in deny rule, keystone path, `POLICY ∩ PROFILE`).

## Visual identity

- **Mark:** the Ward Seal: a round seal with a keyhole whose shaft is crossed
  by three ward bars (the wards in a lock, which stop every wrong key from
  turning) and one drop of wax at two o'clock. Ink on paper, bars in seal
  vermillion; the nightly build lights the drop in lamp amber.
- **Palette:** paper (`#F3EEE3` ground, `#FBF8F1` sheet, `#1A1814` ink,
  `#B3301A` seal, `#B86A00` lamp) and night (`#0B0E14` ground, `#141A26`
  surface, `#ECE8E1` foreground, `#FF7A5C` seal, `#FFB547` lamp). The
  dashboard's factory theme slug is `junction`.
- **Type:** Fraunces (wordmark and display) and IBM Plex Sans (body and UI),
  bundled under `website/public/fonts`; no font CDN. The wordmark is
  "warding" in Fraunces wght 600, opsz 144, tracked -0.015 em.
- **Motif:** the seal and the refusal, the lit window, the three ward bars.
  No mascot.
- **Source of truth:** [`assets/brand/build.py`](assets/brand/build.py)
  generates the mark, glyph, wordmark, lockups, README banner, app icons
  (`.png`/`.ico`/`.icns`, nightly variant), tray template, PWA icons, the
  gateway's `/logo.png`, and the DMG/NSIS installer art.

## Security and harness (do not weaken)

Keystone paths under the data home stay in `security._SENSITIVE_HOME_DIRS`.
Governance is `effective = POLICY ∩ PROFILE` at Warding's own PreToolUse gate.
Computer use stays ungoverned by scopes. Harness identity is positive
(`is_kiro_backend` / membership sets), never "not Claude". An added harness
adapts; it does not widen the Kiro path. Every security claim carries its
mechanism in the same sentence, and "unaudited by a third party" wherever the
charter is described.
